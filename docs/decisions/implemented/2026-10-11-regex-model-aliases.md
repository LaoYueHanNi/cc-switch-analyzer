# DR: 正则模型别名与统一识别

Status: implemented

## Problem

云端 model-price-table 冻结历史 aliases，新增名称改用 aliasPatterns；旧解析器丢弃该字段，只维护逐个名称的映射，无法识别正则覆盖的新名称。前端模型卡片、趋势、家族筛选和费用对比各自遍历 aliases，与后端大小写不敏感的识别也不一致。

## Decision

Rust ModelResolver 与前端 createModelResolver 使用相同的全表阶段：modelId 精确匹配、历史与用户别名精确匹配、aliasPatterns 兜底。精确比较只折叠 ASCII 大小写；正则采用忽略大小写的可移植子集（固定字面名称、转义标点、分组、分支和可选项），校验完整匹配范围，拒绝末尾换行、通配符、无界量词、前后查找和引擎专有语法。不删除名称前后缀，不猜测模型变体。跨模型歧义返回解析错误并记录日志；计费和页面关联不选择任何候选，多条规则命中同一模型只算一次。

正则按定价快照编译，名称解析使用最多 4096 项的结果缓存。Rust 刷新先完整构建新引擎，成功后替换旧引擎；非法下载在写库前拒绝，损坏缓存不会清空已有有效引擎。基础定价覆盖先解析云端名称（含正则），仅真正未知的名称注册为自定义模型；用户时间规则也归属到解析后的规范模型。

应用自有 pricing.db 的 v17 迁移添加 cloud_pricing_cache.alias_patterns，保存 JSON 数组，旧行默认 []。cloud_pricing_cache_format=2 只在完整定价表事务写入成功后保存；下载版本相同但缺少格式标记时仍补写缓存，避免旧客户端已缓存新版本却丢弃正则字段。离线期间旧价格和历史别名仍可用，后续下载恢复完整规则。外部数据源数据库不参与迁移。

刷新时先按云端快照解析用户别名的归属，再注册这些精确别名，避免自指别名或遍历顺序遮蔽历史名称的正则归属。应用自有库中的覆盖价、上下文档位、时间规则及用户别名通过事务归并到规范 ID；未知自定义模型保持原键。自定义别名归属存在链式或循环引用时拒绝迁移，保留原数据及有效引擎，避免移动存储键时相互覆盖。覆盖价同一档位冲突保留 updated_at 较新的完整价格节点（含峰谷），同秒优先已有规范键，其他历史键按字典序；时间规则同范围同档位保留最大 id，未冲突的范围、档位及 id 保留，用户别名合并去重。所有按模型名称的写入和删除先解析规范 ID，歧义返回错误；前端从用量别名打开编辑时提交规范 ID，使编辑、恢复默认及删除别名与卡片展示的归属一致。

IPC 返回 aliasPatterns。前端统一解析供模型卡片、趋势费率、家族、费用对比和定价完整名称搜索使用；关键词仍做大小写不敏感的包含搜索。别名管理只读展示云端正则及历史名称，本地用户别名保持普通精确名称；增删别名后重查统计费用。

## Alternatives considered

**删除历史 aliases，只匹配正则：** 上游仍有大量模型只提供历史名称；删除会失去兼容性。

**把正则展开成别名数组：** 重新引入逐名称维护和组合枚举成本，无法直接消费上游规则。

**只更新 Rust 计费：** 页面仍会错误显示缺少定价或归入其他家族，费用对比也会找不到来源规则。

**引入可编辑的本地正则：** 当前需求是消费云端定价规则，本地输入继续保持精确名称，避免扩大用户数据迁移和编辑校验范围。

## Consequences

新名称随定价表规则更新生效，前后台和各页面使用同一识别契约。共享测试样例验证大小写、阶段优先级、歧义、完整匹配和 fast/mini/pro/max 身份边界；Rust 测试覆盖旧缓存迁移、同版本补写、错误数据保留有效定价、上下文档位、时间规则、峰谷、本地覆盖及后台今日费用与前台统计一致性。

代价是引入 regex 直接依赖、编译后的规则和有界缓存；跨模型规则交集无法仅靠有限名称枚举证明无冲突，未知名称的歧义在实际解析时检测并拒绝。忽略大小写限制为 ASCII，与上游模型名称约定一致。老缓存首次升级时需成功联网才能补齐以前丢弃的正则字段。
