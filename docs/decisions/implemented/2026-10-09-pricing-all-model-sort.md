# DR: 定价页全部模型排序视图

Status: implemented

## Problem

定价页原先按家族分组展示模型，跨家族比较模拟费用时需要在多个分组之间来回查看，难以快速找到费用最高或最低的模型。

## Decision

定价工具栏增加展示模式、排序字段和排序方向按钮。默认继续按家族分组，以保持原有浏览习惯；切换到“全部模型”后，将当前筛选结果放入同一个卡片网格；切换到“排行榜”后，以紧凑行展示同一排序结果。两种新视图都支持按模拟费用或模型名排序，并通过一个上下箭头按钮切换升序与降序。家族筛选、模型筛选和四项模拟 Token 在所有展示模式下共用。

## Alternatives considered

**只在现有家族分组内排序：** 不能解决跨家族比较的问题，用户仍需手工记忆各分组的结果。

**改为固定表格并移除卡片：** 虽然适合密集浏览，但会削弱定价卡片已有的时间规则、上下文档位和编辑入口的可见性；因此保留卡片视图，并将排行榜作为可切换的轻量总览。

**提供 Token 或请求数排序：** 定价页的模拟 Token 对所有模型相同，且当前定价数据不承载模型请求数，提供这些排序会产生没有实际区分度或来源不明的结果。

## Consequences

用户可以在保留现有卡片交互的同时，一次查看并排序所有模型，也可以用紧凑排行榜快速浏览名次并进入编辑。默认视图不变；排序只影响当前内存中的展示顺序，不改变定价数据或持久化配置。
