# DR: Rust 后台采集与状态栏及时更新

Status: implemented

## Problem

[轻量模式审计](../../audits/2026-10-10-lightweight-mode.md)确认：销毁 WebView 后，七类本地扫描源失去前端定时调度，原生状态栏查询虽然存活却一直读旧数据。启动恢复依赖前端；Windows 插件在实际连接失败时不发现新端口；查询失败可能伪装成零用量。完整图表预计算、历史记录在 Rust 中过滤及 30 秒结果缓存增加延迟。窗口恢复还存在外部尺寸被当作内部尺寸、旧几何覆盖已有窗口及异步销毁期间重建的风险。

用户明确要求 Cursor 后台可以不自动同步，以减少云端请求频率。因此本地持续采集与 Cursor 缓存展示需要保留不同的同步边界。

## Decision

Rust 启动时恢复只读数据源、禁用状态与缓存定价；界面重建复用内存态。`background_collection.rs` 常驻线程逐轮扫描已启用的 ZCode、Proma、DSH、MiniMax、Antigravity、Kimi、PI，每轮结束后等待 5 秒，前端刷新共享采集闸门。采集持独立应用库连接，长扫描不占用界面设置的 Rust Mutex；SQLite 写事务仍由 WAL 与 busy timeout 协调。DSH 始终按持久化模式及自定义目录路由。Cursor API 调用留在原有前台 24 小时有效期与手动命令中，后台只读取下载缓存。

外部数据库保持只读。ZCode / MiniMax 导入游标的变更戳包含主库和 WAL 元数据；派生用量只写应用库。禁用配置升级为类型 + 路径，兼容旧路径设置。七类派生源按日期范围在 SQL 读取，应用库增加 `(source, created_at)` 索引，外部库不建索引。

`today_query.rs` 使用独立长驻只读连接，复用去重、Cursor 基础档位及定价引擎，逐请求汇总今日 Token / 费用，避免完整图表计算。SQL 连接直接读取当前提交，只有 Cursor CSV 变化需要重开；本机 Hook 刷新最多每 5 秒一次。源开/查询失败显式返回，全部失败返回错误，部分失败附 `stale/errors` 并重试失败连接，采集失败也进入状态。`updatedAt` 表示查询时间，不代表全部上游都在该时间同步成功。

Windows HTTP 按请求计算，删除 30 秒结果 TTL；停服等待监听线程释放端口。新版插件按 `tz=local` 请求，在实际发送/接收失败后每次至多探测一个候选端口，整轮失败退避、成功重置。查询错误显示 `--`；stale 部分结果的展示判定后来调整为仅全部源失败才显示 `--`，见[插件部分失败展示决策](2026-10-10-traffic-monitor-stale-display.md)。macOS 每轮查询后等待 5 秒，部分结果以 `*` 标记，全部失败显示 `—`；generation 与停止标志同时在查询后和主线程回调检查，旧轮次不能重新写回文字。

本机自然日边界分别换算当天和次日午夜，费用峰谷匹配使用每条记录的实际时区偏移，支持分钟时区及夏令时。HTTP 兼容旧整数小时 `tz`，增加 `tz_minutes` 与 `tz=local`。

[后台窗口决策](2026-09-30-headless-background-mode.md)继续采用销毁后按需重建；切换在主线程协调四态，Destroyed 确认前的唤起排队，失败回滚外观，托盘文案所有入口一致。窗口保存正常态内部尺寸和位置，仅新建时恢复；旧外部尺寸记录不套用。

## Alternatives considered

**保留前端定时器或隐藏 WebView 维持采集**：无法满足销毁界面释放资源的目标，也使前台和后台的数据行为分叉。

**由 HTTP 与菜单栏各自扫描**：多个独立入口重复遍历和入库，服务关闭时还会丢失采集；常驻采集独立于两个展示开关。

**先建立文件监听与共享快照**：可以进一步减少遍历/聚合，但多平台监听、目录变化、配置失效及错误状态增加本次复杂度。采用已有增量扫描器的 5 秒补扫与当日专用按需汇总；后续有实测瓶颈时再引入监听或版本化快照。

**频繁自动同步 Cursor**：违背用户降低请求频率的约束；Cursor 排除在本地持续更新目标之外。

## Consequences

无 WebView 时本地来源仍能持续导入，状态栏与前台使用一致的请求去重和费用规则。通常目标为数据可读后约 5–10 秒加扫描/查询耗时反映到状态栏；Windows 还受宿主轮询周期影响，Antigravity 仍依赖 language server。失败不会成为可信的零值或无提示的部分统计。

代价是常驻 Rust 连接和扫描工作、按请求聚合当天记录，以及每源循环的耗时；不承诺零延迟或所有故障下的最新统计。旧版 DLL 需替换为新构建，两种架构 DLL 均嵌入应用。测试命令包括 `pnpm test`、`pnpm test:rust`、`traffic-monitor-plugin/test.bat` 和决策校验；原生窗口、多屏、睡眠唤醒及 macOS UI/内存仍需目标设备验收。
