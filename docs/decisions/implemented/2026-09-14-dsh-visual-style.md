# DR: 分析器视觉改为 DSH 冷蓝中性 + 少岛分声部

Status: implemented

## Problem

分析器暗色是午夜紫蓝，强调色混用 Naive `#4a90d9`、`--color-blue` `#2980b9` 和多处 `#18a058`；筛选/摘要/图表都画成岛，驾驶舱密度被框线切碎。要对齐 DeepSeek Harness 的冷蓝中性气质，但不能把「同时横比 N 个对象」改成单列聊天壳。

## Decision

主界面按方案 B 落地：全局 token 为 DSH 近黑蓝灰（`#151517` / `#232324`）+ DeepSeek 蓝（亮 `#4176e6`，暗 `#567efe`）；Naive `primaryColor` 与 `--color-blue` 对齐；命中率走蓝，不再用荧光粉。筛选、摘要、工具条、趋势图去岛；只有模型、供应商、项目、任务、定价卡保留为对比单元。卡内名称/费用/Token 为主声，单次与命中率和声，PricingGrid 休息态压低、悬停或点击拉满，不淡化邻卡。会话二级默认一行，点开再展开热力与分解，恢复终端入口留在折叠外。实时表无卡片壳，数据源圆点与设置页同一套中性色。不搬 DSH 插件架构，不改 `zoom: 1.1`，字体保持 Inter。对照基准为 [`docs/demos/dsh-style-preview.html`](../../demos/dsh-style-preview.html)。

## Alternatives considered

- **只换色（方案 A）** —— 紫框和岛还在，气质到不了 DSH。
- **整页改成 DSH 聊天壳（方案 C）** —— 分析器任务是横比 N 个对象，单列阅读流会伤对比。
- **运行时新旧皮肤开关** —— 两套 token 长期分叉；用分支验收，不满意回退该步提交即可。
- **主按钮改成 DSH 近黑/近白** —— 分析器主操作需要可扫读的强调色，仍用 DeepSeek 蓝。

## Consequences

- 换来：亮/暗主界面与 DSH 冷蓝中性对齐；驾驶舱少岛后对比单元更突出；费率表分声部降低休息态噪音；会话二级可先扫费用再展开细节。
- 代价：去岛后摘要扫读变弱（实机可接受）；会话热力默认收起，需点开才看见；数据源圆点去荧光后区分变弱（设置页仍有文字名）；设置弹窗未跟大改版，CSV 预览等处仍可能残留旧强调色。
